Fungi

Solo is a local match against bots. To play online, enter a game server as host:port. Spectate watches the whole arena without playing.

Left-drag from a colony: to empty space = eject, to a node = grow hypha (flows start → end)
Left-click a hypha = reverse its flow · Right-click a hypha / wall = cut / remove
Right-drag from a colony = build wall (crossbar blocks lines)
Right-drag empty space / WASD = pan · Wheel = zoom · R = new round
